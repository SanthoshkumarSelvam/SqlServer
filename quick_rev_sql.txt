01 Question: The HR manager wants a list containing only employees who earn more than ₹30,000.
Answer: SELECT * FROM EMPLOYEES WHERE SALARY > 30000;

02 Question: The report should show the employee's name as EMP_NAME and salary as PAY.
Answer: SELECT FIRST_NAME AS EMP_NAME, SALARY AS PAY FROM EMPLOYEES;

03 Question: The manager wants to know how many different departments currently have employees.
Answer: SELECT DISTINCT DEPARTMENT_ID FROM EMPLOYEES;

04 Question: Find employees whose salary falls between ₹25,000 and ₹50,000.
Answer: SELECT * FROM EMPLOYEES WHERE SALARY BETWEEN 25000 AND 50000;

05 Question: Prepare a list of employees working in departments 10, 20, or 30.
Answer: SELECT * FROM EMPLOYEES WHERE DEPARTMENT_ID IN (10,20,30);

06 Question: Find employees whose names begin with the letter S.
Answer: SELECT * FROM EMPLOYEES WHERE FIRST_NAME LIKE 'S%';

07 Question: Find employees whose names contain the characters an anywhere.
Answer: SELECT * FROM EMPLOYEES WHERE FIRST_NAME LIKE '%an%';

08 Question: Find employees whose names contain exactly 6 characters.
Answer: SELECT * FROM EMPLOYEES WHERE LENGTH(FIRST_NAME) = 6;

09 Question: Prepare the salary report with the highest-paid employees appearing first.
Answer: SELECT * FROM EMPLOYEES ORDER BY SALARY DESC;

10 Question: Show employees alphabetically, but for employees with the same name, show the higher salary first.
Answer: SELECT * FROM EMPLOYEES ORDER BY FIRST_NAME ASC, SALARY DESC;

11 Question: The HR team wants to see only employees who have received a commission.
Answer: SELECT * FROM EMPLOYEES WHERE COMMISSION_PCT IS NOT NULL;

12 Question: Find employees for whom no commission information has been recorded.
Answer: SELECT * FROM EMPLOYEES WHERE COMMISSION_PCT IS NULL;

13 Question: In the final report, missing commission values should appear as 0.
Answer: SELECT FIRST_NAME, NVL(COMMISSION_PCT,0) AS COMMISSION FROM EMPLOYEES;

14 Question: The management report should display employee names completely in capital letters.
Answer: SELECT UPPER(FIRST_NAME) FROM EMPLOYEES;

15 Question: Prepare a report showing how many characters are present in each employee's first name.
Answer: SELECT FIRST_NAME, LENGTH(FIRST_NAME) AS NAME_LENGTH FROM EMPLOYEES;

16 Question: Find the location of the letter A within each employee's first name.
Answer: SELECT FIRST_NAME, INSTR(FIRST_NAME,'A') AS POSITION FROM EMPLOYEES;

17 Question: The report should show only the first three letters of every employee's first name.
Answer: SELECT FIRST_NAME, SUBSTR(FIRST_NAME,1,3) AS FIRST_3 FROM EMPLOYEES;

18 Question: Some employee names contain unwanted spaces around them. Clean the names before displaying them.
Answer: SELECT TRIM(FIRST_NAME) FROM EMPLOYEES;

19 Question: The report should show first name and last name together as one complete name.
Answer: SELECT FIRST_NAME || ' ' || LAST_NAME AS FULL_NAME FROM EMPLOYEES;

20 Question: Salary values contain decimal portions, but management wants them rounded to two decimal places.
Answer: SELECT FIRST_NAME, ROUND(SALARY,2) AS SALARY FROM EMPLOYEES;

21 Question: Management wants only the whole-number portion of salary without rounding it.
Answer: SELECT FIRST_NAME, TRUNC(SALARY) AS SALARY FROM EMPLOYEES;

22 Question: Check the remainder obtained when each employee's salary is divided by 1000.
Answer: SELECT FIRST_NAME, MOD(SALARY,1000) AS REMAINDER FROM EMPLOYEES;   (or)
        SELECT FIRST_NAME FROM EMPLOYEES where MOD(SALARY,1000)=0;

23 Question: Prepare a list of employees earning more than ₹40,000 who also belong to department 20.
Answer: SELECT * FROM EMPLOYEES WHERE SALARY > 40000 AND DEPARTMENT_ID = 20;

24 Question: Find employees who are either from department 10 or earn more than ₹60,000.
Answer: SELECT * FROM EMPLOYEES WHERE DEPARTMENT_ID = 10 OR SALARY > 60000;

25 Question: Find employees who don't belong to departments 10, 20, or 30.
Answer: SELECT * FROM EMPLOYEES WHERE DEPARTMENT_ID NOT IN (10,20,30);

26 Question: Find employees whose second character is A, whose salary is between ₹30,000 and ₹70,000, and who receive commission.
Answer: SELECT * FROM EMPLOYEES WHERE first_name like '_a%' AND SALARY BETWEEN 30000 AND 70000 AND COMMISSION_PCT IS NOT NULL;

27 Question: The report should show No Commission instead of an empty commission value.
Answer: SELECT FIRST_NAME, NVL(TO_CHAR(COMMISSION_PCT),'No Commission') AS COMMISSION FROM EMPLOYEES;

28 Question: The company wants to guarantee that two employees can never have the same employee ID. Which rule should be applied?
Answer: PRIMARY KEY (EMPLOYEE_ID)

29 Question: The company does not want employees to enter a salary of zero or a negative salary. Which rule can enforce this requirement?
Answer: CHECK (SALARY > 0)

30 Question: An employee's department number must match a valid department number maintained in another table. Which rule should be used?
Answer: FOREIGN KEY (DEPARTMENT_ID) REFERENCES DEPARTMENTS(DEPARTMENT_ID)
